# Uso de Inteligência Artificial

A inteligência artificial foi utilizada como apoio durante o desenvolvimento do projeto.

## Apoio utilizado
- Organização das funcionalidades e dos requisitos do projeto.
- Sugestões de estrutura para HTML, CSS e JavaScript.
- Apoio na integração com a PokéAPI usando `fetch`.
- Sugestões para implementar cadastro, listagem, edição e exclusão com `localStorage`.
- Apoio na validação dos campos e na documentação.

## Participação do aluno
O aluno deve revisar, testar e compreender o código entregue, realizar as adaptações necessárias e conseguir explicar o funcionamento das páginas, dos eventos, da API e do armazenamento local.

## Observação
A IA foi utilizada como ferramenta de apoio. O conteúdo final deve ser conferido e validado pelo aluno antes da entrega.
